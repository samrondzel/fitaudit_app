# Fitaudit Food Tracker

Локальное Flask-приложение на базе `fitaudit_cache.jsonl`.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Открой в браузере:

```text
http://127.0.0.1:5000
```

## Что есть

- Поиск продуктов с подсказками.
- Карточка продукта с инпутом граммов от 0 до 3000.
- Автоматический пересчет КБЖУ, витаминов, минералов и процентов нормы.
- Кнопка «Добавить» добавляет продукт в «Съел сегодня» без автоматического перехода на вкладку дневника.
- Вкладка «Съел сегодня»: список съеденных продуктов и общая таблица по всем параметрам.
- Вкладка «Надо добить норму»: поиск витамина/минерала/КБЖУ-параметра, круговая диаграмма прогресса, топ-20 продуктов по содержанию на 100 г, инпут граммов и добавление продукта в дневник.

## Где хранятся данные дня

Дневник хранится в браузере через `localStorage`. Если открыть приложение в другом браузере или очистить данные сайта, список «Съел сегодня» будет пустым.
